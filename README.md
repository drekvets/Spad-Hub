# Spad Hub - Rock Fruit

Auto Farm, Auto Stats, ESP, Teleport, Speed Hack, NoClip и многое другое.

## How to use

Paste this in your executor:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/drekvets/Spad-Hub/main/Rock%20Fruit%20Spad.Lua"))()
```

## Features

- Auto Farm (Quest + Kill)
- Auto Kill Boss
- Auto Spawn Boss
- Auto Rebirth (Lv.22000+)
- Auto Stats
- Auto Open Chests (Diamond / Moon)
- Auto Potions (X2 Rebirth, EXP, Lucky, Item, Diamond)
- ESP (Players / NPCs / Mobs)
- Speed Hack, NoClip, FullBright
- Anti-AFK
- Teleport (Islands / NPCs)
- FPS Boost
- Discord Contact

## Toggle Menu

Press **LeftAlt** to open/close the menu.
